# AI This Week

The data source for the [AI This Week](https://jasonhorne.org) page on jasonhorne.org.

`index.html` is a single page listing how I use AI tools each week. It is
regenerated from local weekly notes by `build_site.py` and served via GitHub
Pages. The live jasonhorne.org page fetches `index.html` on load, so the
website updates itself with no manual editing.

Built and maintained with Claude Code.
